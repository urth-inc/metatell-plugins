# Examples

This directory contains runnable reference implementations for metatell plugin
use cases.

- [password-collection-modal](./password-collection-modal/README.md) shows a
  password collection flow implemented as a `CustomOverlay` plugin.
- [external-api-auth](./external-api-auth/README.md) shows a plugin calling an
  external API with a plugin API token and a sample backend verifying that
  token.

These examples were migrated from
[`urth-inc/metatell-official-plugins`](https://github.com/urth-inc/metatell-official-plugins)
at commit
[`33474cab`](https://github.com/urth-inc/metatell-official-plugins/commit/33474cab599ad4bb5ab3cb3598b5798793664c25).
